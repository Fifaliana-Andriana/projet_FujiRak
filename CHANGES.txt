MODIFICATIONS DU PROJET FUJIRACK

=== VERSION ACTUELLE ===

1) INTERFACE ADMIN - GESTION DES UTILISATEURS
- Page admin complète pour lister tous les utilisateurs avec design moderne
- Affichage du tableau des utilisateurs avec : ID, Nom, Email, Classe, Rôle, Date d'inscription, Statut
- Bouton "Ajouter Utilisateur" en haut pour ajouter un nouvel utilisateur (date d'inscription automatique = date du jour)
- Modale pour créer un nouvel utilisateur avec tous les paramètres (prénom, nom, email, mot de passe, classe, rôle)
- Bouton "Modifier" pour chaque utilisateur (non utilisé pour l'instant)
- Bouton "Supprimer" avec alerte JavaScript pour confirmation avant suppression
- Design moderne avec gradient, badges colorés, animations et responsive
- Barre latérale de navigation avec menu admin
- Toutes les colonnes affichées correspondent aux colonnes réelles de la base de données

2) MODÈLE USER - MÉTHODES AJOUTÉES ET CORRIGÉES
- findById($userId) : Récupère un utilisateur par son ID
- updateAvatar($userId, $avatarPath) : Placeholder pour mise à jour photo de profil
- changePassword($userId, $newPassword) : Change le mot de passe de l'utilisateur
- create() : Corrigée pour ne pas utiliser les colonnes inexistantes (username, photo)
- getAll() : Corrigée pour utiliser uniquement les colonnes qui existent dans la base de données
- delete() : Supprime un utilisateur par ID

3) CORRECTIONS APPORTÉES
- Suppression de toutes les références à la colonne 'username' (n'existe pas en base)
- Suppression de toutes les références à la colonne 'photo' / 'avatar' (n'existe pas en base)
- Correction du formulaire de création d'utilisateur dans la modale (enlever le champ username)
- Génération automatique d'un username basé sur le prénom et nom (non stocké en base)
- Correction de views/user/profile.php pour ne pas afficher 'username' et 'avatar'
- Adaptation de la méthode create() pour fonctionner sans colonne 'username'
- Utilisation de 'photo' remplacée par validation null pour les avatars

4) RÔLES ET PERMISSIONS
- Rôle "user" : Utilisateur standard
- Rôle "admin" : Administrateur avec accès à la gestion des utilisateurs
- Classe "simple" : Classe utilisateur standard
- Classe "gold" : Classe utilisateur premium
- Classe "plus" : Classe utilisateur premium plus

COLONNES DE LA TABLE USERS (RÉELLES)
- id : INT
- nom : VARCHAR(100)
- prenom : VARCHAR(100)
- email : VARCHAR(255)
- password : VARCHAR(255)
- classe : ENUM('simple', 'gold', 'plus')
- role : ENUM('user', 'admin')
- verification_code : VARCHAR(6)
- code_expiration : DATETIME
- is_verified : TINYINT(1)
- is_active : TINYINT(1)
- last_login : DATETIME
- date_creation : DATETIME
- date_modification : DATETIME
